# CDROM

## Abstract
This project is a personal introduction to video game development. Its main objective is the creation of a demo for a metroidvania video game.

### This project is a work in progress

## Intructions
- Download Unity Hub
- Add project
- Install recommended Unity's version (automatically shown in Unity Hub)
- Open the project and select in window Project Assets/Scenes/Menu to run the game in Unity (if you try to run it anywhere else it will crash)
